# Medal-of-Honor-Airborne-Unofficial-Remaster-
Medal of Honor: Airborne (Unofficial Remaster) reworks Airborne with a mod loader and many mods. It adds a new HUD with a full objective compass, 1:1 damage, enemy AI that scales with the difficulty, lean, hold breath, stamina, suppression, ragdolls, 5x view distance, retuned tanks and a new look for every map.
